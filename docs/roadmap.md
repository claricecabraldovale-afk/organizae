# Roadmap inicial

## Fase 1 — Fundação

- Definir repositório técnico.
- Documentar arquitetura.
- Definir regras contra Lovable Cloud.
- Auditar Supabase.

## Fase 2 — Backend

- Criar migrations.
- Configurar autenticação.
- Criar tabelas e RLS.
- Criar buckets privados.
- Criar tipos TypeScript.

## Fase 3 — Interface

- Criar PWA no Lovable conectado ao GitHub.
- Implementar navegação.
- Criar dashboard.
- Criar cadastro de documentos.
- Criar anexos e busca.

## Fase 4 — Recursos avançados

- Compartilhamento.
- Exportação em PDF.
- Criador de documentos com IA.
- Backup e restauração.

## Fase 5 — Validação e publicação

- Testes mobile e desktop.
- Testes de segurança.
- Testes offline.
- Escolha do serviço de deploy.
- Publicação do MVP.
